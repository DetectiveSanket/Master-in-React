    --------------------------------------------------
        2️⃣ STATIC HOSTING
    --------------------------------------------------    

        🧠 Theory:
        - React apps are static SPA apps (Single Page Applications)
        - Can be deployed on any static hosting service

        2a. Netlify
        -----------
        • Popular, easy to use, supports CI/CD

        ⚙️ Steps:
        - Connect your GitHub repo
        - Set build command: npm run build
        - Publish directory: build/
        - Get automatic HTTPS & continuous deploys on push

        2b. Vercel
        ----------
        • Specialized for frontend frameworks, especially React & Next.js

        ⚙️ Steps:
        - Sign in via GitHub
        - Select your repo
        - Vercel detects React project automatically
        - Deploy with one click
        - Get preview URLs for every branch

        2c. GitHub Pages
        ---------------
        • Free static hosting for open-source projects

        ⚙️ Steps:
        - Install gh-pages: npm install gh-pages --save-dev
        - Add to package.json:
        "predeploy": "npm run build",
        "deploy": "gh-pages -d build"
        - Run: npm run deploy
        - App is live at https://username.github.io/repo-name

        ✅ Use Case: Perfect for portfolio projects, personal sites, and small applications

        3️⃣ ⁡⁢⁣⁣𝗖𝗗𝗡 𝗗𝗲𝗽𝗹𝗼𝘆𝗺𝗲𝗻𝘁⁡

    🧠 Theory

        - CDN (Content Delivery Network) stores your static assets closer to users globally
        - Examples: AWS S3 + CloudFront, Google Cloud Storage, Firebase Hosting
        - Fast load times, scalable, production-ready

    ⚙️ Steps (example S3 + CloudFront)
        - Upload build/ folder to S3 bucket
        - Enable CloudFront CDN for caching and global delivery
        - Point domain to CloudFront distribution

    ✅ Use Case: Enterprise-level deployment or global scale

        4️⃣ ⁡⁢⁣⁣𝗖𝗜/𝗖𝗗 𝗣𝗶𝗽𝗲𝗹𝗶𝗻𝗲𝘀⁡
    --------------------------------------------------

        🧠 Theory

        CI/CD = Continuous Integration + Continuous Deployment

        Automates:
            Testing code
            Running builds
            Deploying to hosting

        ⚙️ Example
            - Tools: GitHub Actions, GitLab CI, CircleCI
            - Sample GitHub Actions workflow .github/workflows/deploy.yml:

        name: Deploy React App
        on:
        push:
            branches: [main]
        jobs:
        build-deploy:
            runs-on: ubuntu-latest
            steps:
            - uses: actions/checkout@v3
            - name: Install Node.js
                uses: actions/setup-node@v3
                with:
                node-version: 20
            - name: Install dependencies
                run: npm install
            - name: Build
                run: npm run build
            - name: Deploy to GitHub Pages
                uses: peaceiris/actions-gh-pages@v3
                with:
                github_token: ${{ secrets.GITHUB_TOKEN }}
                publish_dir: ./build


        ✅ Use Case: Every time you push to main, your React app auto-builds and deploys.
