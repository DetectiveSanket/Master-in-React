📌  KEY INSIGHT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    A lot of developers struggle with these two because they both 
    look like they are "watching" data.
    
    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │   ⚡ useEffect                                                      │
    │   ─────────────                                                     │
    │   The "Side Effect" Specialist                                      │
    │                                                                     │
    │   Examples:                                                         │
    │   • "Once the page loads, go fetch data from Google"                │
    │   • "When this variable changes, send an alert"                     │
    │                                                                     │
    ├─────────────────────────────────────────────────────────────────────┤
    │                                                                     │
    │   🧠 useMemo                                                        │
    │   ─────────────                                                     │
    │   The "Lazy Accountant" Specialist                                  │
    │                                                                     │
    │   Example:                                                          │
    │   • "This math problem is really hard, let's do it ONCE and         │
    │     remember the answer so we don't have to calculate it again      │
    │     until the numbers change"                                       │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘

    ⭐ useEffect is probably the most famous part of React, but it's 
       also the part that makes most developers want to pull their hair out! 😵



┌──────────────────────────────────────────────────────────────────────────────┐
│  1️⃣   WHAT IS useEffect? (The Scenario)                                     │
└──────────────────────────────────────────────────────────────────────────────┘

    Think of useEffect as an "Automatic Reaction" 🤖

    🏢 THE SECURITY GUARD ANALOGY:
    ───────────────────────────────
    
    Imagine you are a security guard at a building:
    
        ┌─────────────────────────────────────────────────────────────────┐
        │                                                                 │
        │   🚶 Component Rendering  →  People walking into the building  │
        │                                                                 │
        │   📋 useEffect            →  Your instruction manual:          │
        │                              • "Every time someone walks in,    │
        │                                check their ID"                  │
        │                              • "Every time the sun goes down,   │
        │                                turn on the lights"              │
        │                                                                 │
        └─────────────────────────────────────────────────────────────────┘
    
    💡 It is code that runs AFTER the UI has been "painted" on the screen.



┌──────────────────────────────────────────────────────────────────────────────┐
│  2️⃣   ⁡⁣⁢⁣THE ANATOMY (The Code Structure)⁡                                      │
└──────────────────────────────────────────────────────────────────────────────┘

    useEffect takes TWO things:
    
        📦 The Function      →  The code you want to run
        👀 Dependency Array  →  The list of things it should "watch"


⁡⁢⁢⁢    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │   💻 CODE STRUCTURE:                                                │
    │   ──────────────────                                                │
    │                                                                     │
    │   useEffect(() => {                                                 │
    │                                                                     │
    │     // 1️⃣ Write your logic here (The "Action")                     │
    │                                                                     │
    │     return () => {                                                  │
    │       // 2️⃣ Optional: Cleanup (The "Eraser")                       │
    │     };                                                              │
    │                                                                     │
    │   }, [/* 3️⃣ The "Watchlist" */]);                                   │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘⁡



┌──────────────────────────────────────────────────────────────────────────────┐
│  3️⃣   ⁡⁣⁢⁣THE THREE MODES (The Secret Sauce 🔮)⁡                                 │
└──────────────────────────────────────────────────────────────────────────────┘

    The most confusing part is the [] at the end. 
    Here is the CHEAT SHEET:


    ╔═════════════════════════════════════════════════════════════════════╗
    ║                                                                     ║
    ║  🔔  MODE A: The "Every Time" Mode                                  ║
    ║      (No Array)                                                     ║
    ║                                                                     ║
    ╠═════════════════════════════════════════════════════════════════════╣
    ║                                                                     ║
⁡⁢⁢⁢    ║  💻 Code:                                                           ║
    ║     useEffect(() => {                                               ║
    ║       console.log("I run on EVERY single render!");                 ║
    ║     });                                                             ║
    ║                                                                     ║
    ║  🎬 Scenario:                                                       ║⁡
    ║     Like a bell that rings every time ANYONE moves                  ║
    ║                                                                     ║
    ║  ⚠️  DANGER: This is rarely used and can SLOW DOWN your app!        ║
    ║                                                                     ║
    ╚═════════════════════════════════════════════════════════════════════╝


    ╔═════════════════════════════════════════════════════════════════════╗
    ║                                                                     ║
    ║  🎫  MODE B: The "Once Only" Mode                                   ║
    ║      (Empty Array [])                                               ║
    ║                                                                     ║
    ╠═════════════════════════════════════════════════════════════════════╣
    ║                                                                     ║
    ║  💻 Code:                                                           ║
    ║     useEffect(() => {                                               ║
    ║       console.log("I run ONLY ONCE when the component starts.");    ║
    ║     }, []);                                                         ║
    ║                                                                     ║
    ║  🎬 Scenario:                                                       ║
    ║     Like a "Welcome!" sign you put up when the store opens          ║
    ║     for the FIRST TIME                                              ║
    ║                                                                     ║
    ║  ✅ Use Case:                                                       ║
    ║     • Fetching data from an API                                     ║
    ║     • Starting a timer                                              ║
    ║                                                                     ║
    ╚═════════════════════════════════════════════════════════════════════╝


    ╔═════════════════════════════════════════════════════════════════════╗
    ║                                                                     ║
    ║  🐕  MODE C: The "Watchdog" Mode                                    ║
    ║      (Array with variables [data])                                  ║
    ║                                                                     ║
    ╠═════════════════════════════════════════════════════════════════════╣
    ║                                                                     ║
    ║  💻 Code:                                                           ║
    ║     useEffect(() => {                                               ║
    ║       console.log("I run only when 'data' changes!");               ║
    ║     }, [data]);                                                     ║
    ║                                                                     ║
    ║  🎬 Scenario:                                                       ║
    ║     A sensor that only turns on the fan when the                    ║
    ║     temperature goes UP 🌡️                                          ║
    ║                                                                     ║
    ║  ✅ Use Case:                                                       ║
    ║     Updating a search result every time the user types              ║
    ║     in the search box                                               ║
    ║                                                                     ║
    ╚═════════════════════════════════════════════════════════════════════╝



┌──────────────────────────────────────────────────────────────────────────────┐
│  4️⃣   ⁡⁣⁢⁣THE "INFINITE LOOP" TRAP ⚠️ (Warning!)⁡                                │
└──────────────────────────────────────────────────────────────────────────────┘

    🚨 This is the #1 MISTAKE! Look at this code:


    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │   ❌ DANGEROUS CODE:                                                │
    │   ──────────────────                                                │
    │                                                                     │
⁡⁢⁢⁢    │   useEffect(() => {                                                 │
    │     setCount(count + 1);  // Changing the state...                  │
    │   }, [count]);            // ...while watching the state!           │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘⁡


    🔄 WHAT HAPPENS?
    ─────────────────
    
        1️⃣  React sees count changed
         │
         ▼
        2️⃣  It runs the effect
         │
         ▼
        3️⃣  The effect changes count
         │
         ▼
        4️⃣  React sees count changed again...
         │
         ▼
        💥 BOOM! Your browser crashes because it's stuck in a loop FOREVER!


    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │  🏆 SENIOR DEV RULE:                                                │
    │  ────────────────────                                               │
    │                                                                     │
    │  ❌ NEVER update a state variable inside a useEffect if that        │
    │     SAME variable is in the dependency array!                       │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘



┌──────────────────────────────────────────────────────────────────────────────┐
│  5️⃣   ⁡⁣⁢⁣THE "CLEANUP" (The Eraser 🧹)⁡                                         │
└──────────────────────────────────────────────────────────────────────────────┘

    Sometimes your effect leaves a MESS! 
    
    For example, if you start a setInterval (a timer), 
    it keeps running even if the user leaves the page! 😱

    ✅ To fix this, we use the Return Function:


⁡⁢⁢⁢    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │   💻 CLEANUP CODE:                                                  │
    │   ────────────────                                                  │
    │                                                                     │
    │   useEffect(() => {                                                 │
    │                                                                     │
    │     const timer = setInterval(() => {                               │
    │       console.log("Tick");                                          │
    │     }, 1000);                                                       │
    │                                                                     │
    │     return () => {                                                  │
    │       clearInterval(timer);  // "Stop the timer when I leave!"      │
    │     };                                                              │
    │                                                                     │
    │   }, []);                                                           │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘⁡

## useEffect 3 part 
    1) useEffect without dependency array
    2) useEffect with dependency array , but arrray is empty [].
    3) useEffect with dependency array , with varible in arrray [count].


╔══════════════════════════════════════════════════════════════════════════════╗
║                                                                              ║
║          🍽️  BONUS: FETCHING DATA (The "Waiter" Scenario)  🍽️               ║
║                                                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝


    🍽️ THE RESTAURANT ANALOGY:
    ────────────────────────────
    
    Imagine you go to a restaurant:
    
        ┌─────────────────────────────────────────────────────────────────┐
        │                                                                 │
        │   1️⃣  Component Renders  →  You sit down at the table          │
        │                             (The UI appears)                    │
        │                                                                 │
        │   2️⃣  useEffect          →  You call the waiter and ask        │
        │                             for the menu (The API call)         │
        │                                                                 │
        │   3️⃣  State Update       →  The waiter brings the menu,        │
        │                             and you change your "memory"        │
        │                             from empty to having a menu         │
        │                             (Setting the State)                 │
        │                                                                 │
        └─────────────────────────────────────────────────────────────────┘


    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │  🏆 SENIOR CODE PATTERN:                                            │
    │  ────────────────────────                                           │
    │                                                                     │
    │  When fetching data, ALWAYS handle THREE things:                    │
    │                                                                     │
    │     📦 Loading  →  Show spinner while waiting                       │
    │     ✅ Data     →  Display the actual data                          │
    │     ❌ Error    →  Handle what went wrong                           │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘


    💻 THE CODE EXAMPLE:
    ─────────────────────

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │   function UserProfile() {                                          │
    │                                                                     │
    │     const [user, setUser] = useState(null);                         │
    │     const [loading, setLoading] = useState(true);                   │
    │                                                                     │
    │     useEffect(() => {                                               │
    │       // We use empty array [] because we only want to fetch ONCE   │
    │       fetch('https://api.example.com/user')                         │
    │         .then(response => response.json())                          │
    │         .then(data => {                                             │
    │           setUser(data);      // Save the data                      │
    │           setLoading(false);  // Stop the "Loading..." spinner      │
    │         })                                                          │
    │         .catch(error => console.error("Oops!", error));             │
    │     }, []);                                                         │
    │                                                                     │
    │     if (loading) return <p>Loading your profile...</p>;             │
    │                                                                     │
    │     return <h1>Welcome, {user.name}!</h1>;                          │
    │   }                                                                 │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘



╔══════════════════════════════════════════════════════════════════════════════╗
║                                                                              ║
║    🤔  ⁡⁢⁣⁡⁣⁢⁣CONFUSION POINT: Does useEffect Run on Every Re-render?⁡⁡  🤔          ║
║                                                                              ║
╚══════════════════════════════════════════════════════════════════════════════╝


    ❓ "At every re-render of component the useEffect runs, 
        even if you pass empty dependency array []. Is this right?"
    

    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │  ❌ NO, that is NOT correct!                                        │
    │                                                                     │
    │  If you pass an empty dependency array [], the code inside          │
    │  the useEffect will NOT run on every re-render.                     │
    │                                                                     │
    │  ⭐ This is the BIGGEST misunderstanding in React!                  │
    │     It's the "Senior Developer" hurdle!                             │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘


    🎫 THE "ONE-TIME TICKET" ANALOGY:
    ───────────────────────────────────
    
    Think of your component as a Movie Theater 🎬
    
        ┌─────────────────────────────────────────────────────────────────┐
        │                                                                 │
        │   🎬 The Render                                                 │
        │      This is the movie playing. Every time the "State"          │
        │      changes, the movie restarts or plays the next scene.       │
        │                                                                 │
        │   🧹 The useEffect with []                                      │
        │      This is the CLEANING CREW                                  │
        │                                                                 │
        └─────────────────────────────────────────────────────────────────┘
    
    
    If you give the Cleaning Crew a "One-Time Ticket" (the empty []):
    
        1️⃣  They ENTER the theater when the movie starts for the 
            very first time (Mounting)
             │
             ▼
        2️⃣  They do their job (Fetch data, set up a timer)
             │
             ▼
        3️⃣  Then they SIT OUTSIDE 🪑
            
            Even if the movie restarts 100 times (100 re-renders),
            they STAY OUTSIDE!
            
            They only come back in if the theater is being 
            CLOSED DOWN for good (Unmounting)

    ╔═══════════════════════════╦══════════════════════════════╦═══════════════╗
    ║     IF YOU WRITE...       ║     THE EFFECT RUNS...       ║      WHY?     ║
    ╠═══════════════════════════╬══════════════════════════════╬═══════════════╣
    ║                           ║                              ║               ║
    ║  No array at all          ║  Every single time the       ║  No "Filter"  ║
    ║  useEffect(() => {...})   ║  component re-renders        ║  is applied   ║
    ║                           ║                              ║               ║
    ╠═══════════════════════════╬══════════════════════════════╬═══════════════╣
    ║                           ║                              ║               ║
    ║  Empty array              ║  Only ONCE                   ║  React sees   ║
    ║  useEffect(() => {...},   ║  (when it first appears)     ║  "Nothing to  ║
    ║  [])                      ║                              ║  watch"       ║
    ║                           ║                              ║               ║
    ╠═══════════════════════════╬══════════════════════════════╬═══════════════╣
    ║                           ║                              ║               ║
    ║  With variables           ║  When it first appears +     ║  React only   ║
    ║  useEffect(() => {...},   ║  whenever count changes      ║  triggers on  ║
    ║  [count])                 ║                              ║  "Watched"    ║
    ║                           ║                              ║  changes      ║
    ║                           ║                              ║               ║

⚠️  ⁡⁣⁢⁣"BUT WAIT! I SAW IT RUN TWICE IN MY CONSOLE!"⁡
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    If you are practicing and you see your console.log inside a 
    useEffect([]) appearing TWICE, you are probably seeing 
    React Strict Mode! 🔍


    ┌─────────────────────────────────────────────────────────────────────┐
    │                                                                     │
    │   🔬 WHAT HAPPENS IN STRICT MODE (Development Only):                │
    │   ────────────────────────────────────────────────────              │
    │                                                                     │
    │      1️⃣  "Mounts"    →  (Runs once)                                │
    │       │                                                             │
    │       ▼                                                             │
    │      2️⃣  "Unmounts"  →  (Cleans up)                                │
    │       │                                                             │
    │       ▼                                                             │
    │      3️⃣  "Mounts"    →  (Runs again)                               │
    │                                                                     │
    │   This makes you THINK it's running on every render,                │
    │   but it's actually just React TESTING your code!                   │
    │                                                                     │
    │   ✅ In a real PRODUCTION app, it only runs ONCE.                   │
    │                                                                     │
    └─────────────────────────────────────────────────────────────────────┘

║  📝 FINAL SUMMARY                                                            ║

║                                                                              ║
